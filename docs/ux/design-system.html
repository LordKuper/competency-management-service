О документе

Визуальный справочник токенов и компонентов из docs/ux/DESIGN.md. Источник истины — DESIGN.md; этот файл генерируется из него и не содержит собственных решений. Тема только светлая, тёмная тема не определена (открытый вопрос).

  • Платформа: web SPA, desktop-first, comfortable density, React + antd 6, управляется из токенов через ConfigProvider.
  • Шрифты: семейство PT (PT Sans, PT Sans Narrow, PT Mono) поставляется в образе приложения; эта страница подгружает PT Sans (400/700), PT Sans Narrow (400/700) и PT Mono (400) с Google Fonts, поэтому превью показывает реальные начертания без установки шрифтов на машине.
  • Превью: статические; состояния hover, pressed и focus нарисованы отдельными образцами. Все значения в превью берутся из токенов DESIGN.md через переменные --ds-*, заданные один раз на корневом элементе.

Формы и границы

Сдержанные слегка скруглённые углы: 4px для контролов, 8px для контейнеров, 2px для мелких элементов.

Границы всегда 1px. Контролы обводятся border-control (3.7:1), контейнеры и разделители — border-subtle. Состояния меняют цвет, а не ширину; ошибка поля — граница danger вместе с иконкой и сообщением.

Возвышение

Плоский корпоративный стиль: иерархия за счёт слоёв поверхностей и границ, тени — только у парящих элементов, цвет тени — navy. Три уровня над плоским.

ТокенЗначение
elevation-nonenone
elevation-sticky0 1px 2px rgba(8, 18, 64, 0.08)
elevation-popup0 4px 12px rgba(8, 18, 64, 0.12)
elevation-modal0 8px 24px rgba(8, 18, 64, 0.16)

Тень никогда не единственный признак границы; у парящих поверхностей остаётся рамка border-subtle. Hover не поднимает карточку.

Движение

Движение объясняет смену состояния или источник появления элемента, но не украшает. Здесь нет анимации: значения приведены таблицей. При prefers-reduced-motion: reduce все переходы отключаются.

ТокенЗначениеПрименение
motion-fast100mshover и focus, переключатели, нажатие кнопки
motion-mid200msdropdown, popover, tooltip, collapse, индикатор вкладок
motion-slow300msмодалка и drawer; максимум для интерфейса
motion-ease-outcubic-bezier(0.215, 0.61, 0.355, 1)появление
motion-ease-incubic-bezier(0.55, 0.055, 0.675, 0.19)уход
motion-ease-standardcubic-bezier(0.645, 0.045, 0.355, 1)изменения на месте
  • Нет переходов дольше 300ms, bounce, parallax, анимации смены маршрутов и зацикленного декора; единственная непрерывная анимация — индикатор загрузки.
  • Данные не анимируются: ячейки матрицы, рейтинги и ранжирование обновляются на месте; значимое изменение отмечается иконкой или текстом.
  • Click-ripple antd отключён всегда; при reduce приложение выставляет токен antd motion=false, shimmer скелетона становится статичным.

Do и Don't

Правила повторяют уже принятые решения DESIGN.md; новых решений здесь нет.

Do

  • Собирать интерфейс только из токенов (через ConfigProvider из DESIGN.md): сначала компонентные токены, затем семантические цвета.
  • primary — одно главное действие страницы или диалога; button-danger — только для деструктивных и необратимых действий, с подписью «глагол + объект».
  • Сопровождать статусный цвет иконкой или словом и всегда показывать цифру уровня в чипе рейтинга (WCAG 1.4.1).
  • Показывать причину рядом с недоступным элементом видимым текстом («Нужно 5 оценок, есть 2»).
  • accent — только заливка с текстом surface-inverse или text-primary, либо метка на surface-inverse.
  • Явно задавать все токены текста antd (secondary, tertiary, quaternary, placeholder) и colorPrimaryBorder = primary.
  • Веса только 400 и 700; data-numeric и выравнивание вправо для сравниваемых чисел.
  • Сетка 4px и размер antd по умолчанию (comfortable); на планшете — control-height-lg.
  • Сохранять кольцо фокуса (focus-ring, на тёмной оболочке focus-ring-inverse).
  • Отмечать текущее состояние словами, а не только цветом: теги, шаги, вкладка, пункт навигации.
  • Держать критические алерты редкими: danger только для блокирующих и необратимых событий.
  • Поставлять шрифты PT в образе приложения самохостом вместе с текстом лицензии.

Don't

  • Не использовать «сырые» hex, px и font-family в UI-коде и макетах; не вводить токен-дубликат.
  • Не ставить accent (1.9:1) или белый текст на accent; не использовать accent для предупреждения или любого статуса.
  • Не использовать веса 500 и 600, курсив, верхний регистр и letter-spacing для кириллицы, compactAlgorithm.
  • Не полагаться только на цвет, только на tooltip или только на тень для смысла и границ.
  • Не показывать disabled-элемент без причины; не убирать кольцо фокуса без равноценной замены.
  • Не добавлять тени статичным панелям, таблицам, карточкам; не поднимать карточку при hover.
  • Не анимировать данные (ячейки матрицы, рейтинги, ранжирование), не делать переходы дольше 300ms, bounce, click-ripple и зацикленный декор; учитывать prefers-reduced-motion.
  • Не перекрашивать чип рейтинга ради сравнения с целью; использовать статусный тег или иконку рядом.
  • Не загружать шрифты, иконки и скрипты из CDN или внешних хостов; не использовать createFromIconfontCN.
  • Не создавать тёмную тему из этих токенов; тема не меняет цвета статусов, цели нажатия и отступы.
  • Не обрезать название компетенции без доступа к полному тексту и не скрывать маркер критичной компетенции.
