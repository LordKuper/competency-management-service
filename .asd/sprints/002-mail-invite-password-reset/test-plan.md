## Risk → check decisions

Номера AC — из `sprint.md` этого спринта. Захват писем — Mailpit `axllent/mailpit:v1.31.4` через универсальный контейнер ядра Testcontainers (уже транзитивная зависимость, пакет не добавляется): тот же образ и SMTP-протокол, что в dev-стеке, REST API для чтения писем, отказ сервера и таймаут проверяются настоящим закрытым портом и «молчащим» TCP-слушателем, поэтому заглушка SMTP и Chaos не нужны. Образ запускается с `MP_SMTP_DISABLE_RDNS=true` и `MP_MAX_MESSAGES=0`: без первого каждая SMTP-сессия ждёт приветствие ~10 с (обратный DNS клиента в Docker Desktop), без второго Mailpit удаляет письма сверх 500.
