## Risk → check decisions

Исходное состояние (pre-strategy run, `commands.yaml` `test`): `dotnet test --solution Competency.slnx` → exit 8, «Запущено ноль тестов»; `npm --prefix web test` → exit 1, «No test files found». Тестов в репозитории не было ни одного. Решение пользователя (decisions-log 2026-10-07, ретро-кандидат 1) разрешает ровно две добавки инфраструктуры: интеграционные тесты API на реальном PostgreSQL через Testcontainers (пакет уже в `tests/Competency.Tests`, есть tech-reference) и Playwright e2e. Хост API в интеграционных тестах — реальный процесс `dotnet Competency.Api.dll` на свободном loopback-порту (одна БД на хост, один контейнер PostgreSQL 18.6 на прогон), а не `WebApplicationFactory`: для `Microsoft.AspNetCore.Mvc.Testing` нет `docs/architecture/tech-reference/*.md`, а правило «Refuse-to-implement» запрещает Tester работать с технологией без неё; процесс не требует новой зависимости и дает настройки на каждый хост (лимит входа, bootstrap-администратор).
